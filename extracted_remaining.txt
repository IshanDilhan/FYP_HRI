3.1.4 Closed-Loop Sim-to-Real Tuning
In this section, the approach is using improvement rather than training once.
The model is tested within the simulation environment. The issues that arise
are carefully observed, including failing to recognize a gesture. The simulation
parameters are varied, including light settings, speed, and noise on the sensor.
This is done until the model is functioning properly within all scenarios.
This part of the work helps bridge the difference between simulations and reality.
Simulations that are too simple for models do not work well on real-world robots.
By gradually changing the simulated environment closer to real-world conditions
,the learned behavior can be transferred to the real-world LIMO robot with little
loss of performance.
3.1.5 Edge Optimization (TensorRT)
After this training process, the Transformer modelΓÇÖs speed and size are optimized
using NVIDIA TensorRT. This step eliminates unnecessary components, optimizes
calculations for Jetson platforms, and adopts faster data representations with
equal accuracy. It is very important for safety reasons because a slow processing
speed can cause the robot to respond late. The model can now run in real time
on a small computer on board thanks to this optimization.
3.1.6 Multimodal ΓÇ¥Golden TrialΓÇ¥ Validation
In this stage, the real world tests are conducted. People interact in the real
world according to different behavior types, including cooperative behavior, goal-
oriented movement, mixed behavior, and emergency behavior. This is where the
robotΓÇÖs understanding of a humanΓÇÖs intention is compared to the actual intention
of the human. This stage demonstrates that the system is functional not only in
a simulated environment but also in a real world environment.

Chapter 5
Conclusion
This project proposes aReal-Time Multimodal Intent-Synthesis Frame-
workto address theΓÇ¥Behavioral RigidityΓÇ¥ problem of the modern service
robots. By integrating four primary non-verbal cues of humans such as Emotion,
Motion, Gesture, and Context, this system moves beyond simple obstacle avoid-
ance toward a deep understanding of human social intent. The technical core of
this proposal lies in the shift from rigid rule-based logic to late-fusion transformer
architecture. This shift allows the robot to use Attention Mechanisms to solve the
problems ofΓÇ¥Social DissonanceΓÇ¥ andΓÇ¥Semantic AmbiguityΓÇ¥. Also, it allows
to weight conflicting signals such as an angry face paired with aΓÇ¥ requestingΓÇ¥ ges-
ture to derive a socially appropriate response. Furthermore, this project mitigates
theΓÇ¥Reality GapΓÇ¥ by utilizing NVIDIA Isaac Sim and Audio2Face to synthesize
high-fidelity datasets with automated ground-truth labeling. This ensures that
the model is trained on complex scenarios that are difficult to capture in the real
world. The importance of this research is emphasized by its focus on Edge-Native
Deployment. By optimizing the framework with TensorRT, the project ensures
that a high-level social intelligence system can run natively on an NVIDIA Jet-
son Orin Nano with latency below 100ms. This makes the robot responsive and
safe in high-end environments such as hospitals and retail stores. Ultimately, this
framework provides theΓÇ¥Social BrainΓÇ¥ for service robots to transition from reac-
tive machines to proactive, intent-aware collaborators. To ensure the performance
of these models is grounded in reality, the project culminates in a Real-WorldΓÇ¥
Golden TrialΓÇ¥ validation. By testing the framework against physical data from
real human volunteers, we will get the definitive metrics needed to prove the sys-
tem is reliable in the unpredictable ΓÇ¥Chaotic RealityΓÇ¥ of human interactions.
This allows to effectively bridge the final gap between simulation and real-world
deployment.
